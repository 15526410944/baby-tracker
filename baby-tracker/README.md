# 宝宝成长记 📱👶

一个可以安装到手机桌面的宝宝成长记录 PWA 应用，像真正的 APP 一样使用。

## ✨ 主要功能

### 🏥 健康档案
- **就医记录** - 医院、科室、症状、诊断、处方、医生
- **疫苗接种** - 常见疫苗快速选择，剂次、批号、接种反应
- **儿保体检** - 身高体重头围，结果和建议
- **用药记录** - 药品名、剂量、频次、原因

### 📅 日常记录
- 🍼 **喂养** - 母乳/配方奶/辅食/喝水/零食，含量和时长
- 😴 **睡眠** - 夜间睡眠和白天小睡，时长和质量
- 🌳 **户外** - 散步、晒太阳、公园等多类型，含天气
- 📖 **故事** - 书名、时长、宝宝反应
- 🧷 **尿布** - 湿/脏/干爽多种状态
- 🛁 **洗澡** - 时长和备注

### 📈 成长发育
- 📏 **身高体重** - 手动记录，绘制成长曲线图
- ⭐ **发育里程碑** - 第一次微笑、翻身、坐、爬、走、叫妈妈、长牙等
- 🏃 **运动发展** - 运动技能及掌握程度

### 📔 成长日记
- 写日记、记录心情
- 按日期排序珍藏回忆

### ⚙️ 实用功能
- ⏰ 自定义每日故事时间
- 🎯 户外时长和睡眠时长目标
- 📤 数据导出/导入（JSON 格式）
- 🔄 时间线视图（首页一览今日所有活动）
- 💾 本地存储，无需登录注册
- 📴 离线使用（PWA + Service Worker）

## 📲 如何安装到手机

### iPhone (Safari)
1. 用 Safari 打开本应用
2. 点击底部的「分享」按钮 📤
3. 选择「添加到主屏幕」
4. 点击「添加」即可

### Android (Chrome/华为/小米等浏览器)
1. 用浏览器打开本应用
2. 点击浏览器菜单（右上角三点/⋮）
3. 选择「添加到主屏幕」或「安装应用」
4. 确认添加

## 🎨 设计亮点
- 温柔的粉色调，适合记录宝宝成长
- 移动优先设计，完美适配手机
- 流畅的动效和触感反馈
- 所有数据本地存储，隐私安全

## 💡 使用建议
1. 首次打开会要求设置宝宝信息（昵称、出生日期等）
2. 在「设置」中可以自定义每日故事时间、户外/睡眠目标
3. 长按首页「快捷记录」按钮可快速添加记录
4. 点击宝宝头像可以随时修改宝宝信息
5. 在「设置」中可以导出数据备份

## 🛠 技术栈
- HTML5 + CSS3 + 原生 JavaScript
- PWA（渐进式 Web 应用）
- Service Worker 离线缓存
- LocalStorage 数据持久化
- Canvas 绘制成长曲线
